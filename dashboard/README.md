# Crypto Data Platform - Dashboard

React + Vite + TypeScript frontend that visualizes the data ingested by the backend at the repo
root. See the root `README.md` and `CLAUDE.md` for the overall architecture and how to run the
whole stack.

## Commands

- Install: `npm install`
- Dev server: `npm run dev` (reads `VITE_API_BASE_URL` from `.env`, see `.env.example`)
- Type-check + build: `npm run build`
- Tests: `npm run test`
- Lint: `npm run lint`
